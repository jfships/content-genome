# Title formulas

Write 3 working titles per surviving idea, each from a different formula. The title and the thumbnail are one promise: note in one line what the thumbnail must show for each title. These are the angle, not the final words: video-genome writes the final title after the thumbnail is locked, so the title adds what the thumbnail doesn't say and never repeats it.

**Rules**
- One clear promise the video pays off within the first 10 seconds.
- 30–50 characters (mobile and suggested panels cut at about 40–50; 90+ underperforms). Put the count next to each title.
- The main hook and the search term the viewer would type (e.g. "Claude Skills") in the first 40–50 characters.
- Numbers help in tech when they make a specific promise ("3 Free Claude Skills…"); not as decoration.
- A year tag helps tech tutorials, not personal stories.
- Nothing the video can't deliver. No invented numbers. Exaggerate the feeling, never the facts.
- In the content language from the Genome; respect the Genome's voice.
- Avoid the words the Genome's house rules ban.

**Shorts / Reels.** The rules above are for long videos. On a Short the title matters little: the on-screen hook text (3–7 words, from frame 1) and the cover line do the work. Write one working title and the cover line (`short-form.md` S11), not 3 titles with thumbnails.

| Slug | Formula | Template |
|---|---|---|
| numbered | Numbered list | N [things] that [outcome] |
| mistake | Mistake frame | Why your [X] [fails / keeps failing] |
| result | Specific result | How I [result] in [time] without [obstacle] |
| gap | Curiosity gap | The [real / strange] reason [surprising fact] |
| versus | Versus | [X] vs [Y]: [the test] |
| insider | Insider reveal | What [experts] won't tell you about [X] |
| warning | Warning | Stop [doing X] (do this instead) |
| transformation | Transformation | From [start] to [end] in [time] |
| superlative | Superlative | The [cheapest / fastest / biggest] [X] in [place] |
| three-tier | Three-tier | $[1] vs $[100] vs $[1,000] [X] |
| question | Question | Is [X] actually worth it? |
| how-to | Direct how-to | How to [specific action] |
| specificity | Specificity anchor | The [exact method / tool] I use for [X] |
