# Steps 7–8. Genome cross-check and completeness check

## 7. Genome cross-check (always, before scoring)

Check the developed idea against each item below. List what fits (one line each, with the Genome wording it matches) and every conflict.

| Check | Read from |
|---|---|
| Run sheet / pacing rules (e.g. max big moments per video) | Genome run sheet or Formats |
| Voice: banned words, phrasing rules | Genome Voice |
| House rules | Genome House rules, `00 Decisions/house-rules.md` |
| Closes / CTA | Genome closes |
| Vertical: does it cut into Shorts/Reels in the kept layouts | Genome vertical system |
| Likeness: generated versions of the creator need reference photos | Genome likeness / asset index |
| Truth rules: every claim real or labeled | `Who I Am.md` truth rules |
| Format fit | Genome Formats |

**Each conflict goes to the creator** in one AskUserQuestion round (up to 4 per round), each with a plain setup of what the rule says and what the idea needs. Options:
- **Exception for this video only**: the rule stays; this video breaks it on purpose. Record it in the Idea Record `## Genome exceptions` AND append a row to `00 Decisions/genome-deviations.md` (create from `templates/genome-deviations.md` if missing). Never edits the Genome.
- **Change the Genome**: the rule itself is wrong. Don't edit it here; note it for brand-genome and say so.
- **Keep the rule**: change the idea to fit.
Recommend one per conflict. Truth-rule conflicts have no exception option: the idea changes or is rejected.

Propose narrow exceptions where possible (e.g. banned hype words allowed only in a parody character's mouth, never the creator's).

**`genome: none`:** check against the three answers (audience, personality, proof), truth basics (no invented numbers, results or quotes) and any rule the creator states. Ask once: "Anything you never do on camera or never say?" Exceptions go in the record only; no deviations log.

## 8. Completeness check (before scoring)

"Done" means every line is `done`, or `open` with an owner and next step. A written file is not done. Show the list to the creator.

| Item | Done when |
|---|---|
| Promise | One line: what the viewer gets |
| Audience | One plain line |
| Why now | One line, or "evergreen" |
| Premise | One-line version of the idea |
| Hook | 2–3 concepts ranked |
| Turn / stakes | What changes and roughly when |
| Viewer takeaway | What they leave with |
| Only-you line | Written, or flagged as missing |
| Proof | Have / need listed, with owners |
| Cast / feasibility | Decided, or in Versions to test |
| Versions to test | None, or every row has versions + test type (paid rows have a quoted cost) and the creator's choice is recorded |
| Genome conflicts | Every one ruled |
| Titles + thumbnail | 3 titles, each with what the thumbnail shows |
| Vertical cutdowns | Which parts stand alone as Shorts/Reels, or "none" |
| Score with evidence | Every line has evidence; guesses marked |
