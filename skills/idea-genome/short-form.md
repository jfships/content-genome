# Step 3 for a Short / Reel (replaces develop.md 3b and Hooks)

Purpose: turn one Short idea into one worked-through Short, with the creator. "Short" means any vertical short video: YouTube Shorts, Instagram Reels, TikTok.

A Short is its own video, never a cut-down of a long one. For a Short the shape is the idea, so it gets settled here, not left to the plan.

**One Idea Record per Short. One idea per Short.**

From develop.md, still run: 3a research, 3c voting page, 3e versions to test, 3f only-you line. This file replaces 3b (question rounds) and Hooks. Answers go under `## Develop rounds` in the record, in the creator's words.

## S1. Source

Ask which one (AskUserQuestion, plain setup per option):
- **Written for vertical (Recommended, the default):** scripted for the tall frame, hook recorded fresh. Footage from a long video is used only as parts (a reaction, a screen, a clip) rebuilt in a tall frame.
- **Mined from a long video:** a moment from a long video. Run `clip-mine` (`catalog/sources.md`) first. Only moments that pass the stranger test (S2) go on, and each is still rebuilt tall with a fresh hook.

A crop of the long edit is never a draft.

## S2. Stranger test (pass / fail)

A stranger who never saw the long video gets the point and gets value from this Short alone.

- Write pass or fail, plus one line of why.
- Fail = reject. Not a low score. It goes in the bank as `rejected` with the reason.
- Common fails: a trailer for another video, bloopers that need the episode, a joke that needs an earlier setup.

## S3. Message

One sentence, 12 words or fewer: what the viewer walks away with.

If it takes two sentences, it's two Shorts (see S12).

## S4. Shape

Pick exactly one shape. The six slugs in `catalog/short-shapes.md` stay valid; the full set of shapes and story arcs, with beats, timings, lines and edit intent, is in script-genome (`catalog/selector.md` first, then the chosen card). When script-genome is installed, run its selector here; otherwise use `catalog/short-shapes.md`.

1. Recommend one, with one line of why, plus one alternative.
2. **The shape is proven by watching it, not by links.** video-genome's tall rough draft is where the creator judges it. Show real example Shorts of the shape in their niche only if they ask: find them live with web search and give the real links. Never invent a link.
3. The creator picks.

The long video's order never transfers. If this Short comes from a long video, the beats are rebuilt in the shape, not kept in the episode's order.

## S5. Hook (three layers, word for word)

The hook lands in the first 1–2 seconds, with all three layers together:
- **First frame:** the creator's face or a striking frame. It must make sense with no context.
- **Spoken line:** the exact words.
- **On-screen hook text:** 3–7 words, visible from frame 1. Write the word count.

Rules:
- Nothing before the hook: no greeting, intro, logo, sting, sound logo or name tag.
- The creator (or their real material) is on screen in the opening. Never open on a generated figure alone.
- Aim for the hook itself to be the first payoff (first laugh, twist or result within 3 s).
- A "rewind" hook (the end first, then back to how) only if the rewound moment passes the stranger test on its own.
- Series label only as "Part N" folded into the hook text, never before it.

Write 2 hook versions if the creator is unsure; rank them. They can go in Versions to test.

All three layers carry the same idea, each in its own words; no layer is ranked first, and the first image must make sense with the sound off. Hook options with their mechanics: script-genome `catalog/hooks.md` (plus `hooks-psych.md`, `hooks-unusual.md`).

## S6. Length and word budget

Use the shortest length that lands the idea.

| Platform | Default length |
|---|---|
| YouTube Shorts | 20–45 s |
| Instagram Reels | 20–60 s |
| TikTok | 25–45 s (61–75 s only if the creator is in TikTok's Creator Rewards) |

Word budget at this video's pace, which depends on the delivery (a rant runs faster than an explanation) and rises as the creator improves: their recent pace for this mode from the Pace log in `00 Decisions/voice-kit.md`, else a mode default (explain ≈2.4, story ≈2.6, rant ≈3.0 w/s; script-genome `write/budget.md`). Table at 2.4: After the edit trims gaps, spoken pace usually lands at 2.6–3.0 w/s; that is video-genome's measure, not the planning number.

| Length | Words |
|---|---|
| 15 s | ~36 |
| 30 s | ~72 |
| 45 s | ~108 |
| 60 s | ~144 |

Write the target length and the word cap. The script must fit the cap. Footage builds may run over and get cut after watching; the script may not.

The creator's own words (voice memos, notes) are the base, not the limit. Once the shape and tone are known, restructure them, reweight them (the strongest item goes first, as the hook, or last, as the payoff; never buried in the middle) and propose new lines in the creator's tone, each marked "new" so the creator keeps or cuts it. Never invent facts.

## S7. The last line (exact)

Write the exact last line. It is one of:
- **Payoff:** the result or answer lands.
- **Button:** one short line that closes the joke or point.
- **Hold:** a deadpan hold of 1 s or less.
- **Loop:** the last line runs into the first, in words or picture.

Never: an outro, "thanks for watching", a subscribe ask, an end card, a sting at the end, or words that announce the end.

Endings and any ask with their mechanics, and which asks fit the account's current stage (read from the brand's growth plan, `00 Decisions/growth-plan.md` `## Growth state` (growth-genome)): script-genome `catalog/endings.md`. With no growth plan, the only ask is an optional situational send line ("for the friend who…").

## S8. Send reason

One line: who would send this to someone, and why. ("A cook sends it to the friend who always overpays for knives.")

No real send reason usually means no message. Go back to S3.

## S9. Goal and ending per platform

One line each:
- **YouTube Shorts:** name the long video it points to (for the Related video link), or "none". Shorts and long videos are recommended separately; Shorts are ranked on viewed vs swiped away.
- **Instagram:** reach on its own (sends, few skips in the first 3 s). Any ask must fit the account's stage (script-genome `catalog/endings.md`, "Stage-aware asks"); never an end card.
- **TikTok:** sound on. Trending audio may be added in the app, low under the voice.

Skip a platform the creator doesn't post on; write "not posting".

## S10. Cast and tone

Ask only if still open: who's on screen (likeness check, SKILL.md, before any generated version of the creator) and how it should feel, one plain example per option.

Turn / stakes is a long-video question; don't ask it here.

## S11. Cover line

The cover (Instagram grid, YouTube Shorts thumbnail) is one short line plus the frame it sits on. Write it. It can match the hook text. A working title is enough for the title field; on a Short it matters little.

## S12. Overlap rule

Two Shorts that overlap are one Short, unless each passes the stranger test with a different message. Same message = keep the stronger one; the other goes in the bank as `rejected` (`overlaps IDEA NNN`).

## The script itself

When script-genome is installed, it writes the script from these answers (its job A) and returns a script card: one row per beat with the line, screen text, picture, edit intent and the word that triggers it. Save the card with the record; video-genome builds from it.
