## Sound-effect roles (pick 2–3 options per role)

| Role | Options (C / R / F) |
|---|---|
| Whoosh (wipes) | air whoosh (C) · cloth swish (R) · cartoon zip (F) |
| Tick (counters, typing) | soft click (C) · mechanical keyboard (R) · old typewriter (F) |
| Hit (big type lands) | deep thud (C) · paper slap (R) · taiko drum (F) |
| Click (UI, cursor) | soft UI click (C) · retro mouse click (R) · bubble pop (F) |
| Riser (before a reveal) | synth riser (C) · reversed cymbal (R) · slide whistle up (F) |
| Drop / stop (punchline) | bass drop (C) · record scratch (R) · sad trombone (F) |
| Success | soft chime (C) · cash register (R) · level-up arpeggio (F) |
| Fail | low buzz (C) · error beep (R) · cartoon boing (F) |
| Their own (2–4 from the creator's world) | paper, kitchen, workshop, keyboard, nature, city, game sounds, the creator's own voice sounds |
