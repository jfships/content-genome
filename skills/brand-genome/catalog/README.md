# Catalog: every option, for every part of the Genome

The creator builds a style without knowing any design words. They never describe what they want; they react to options shown as pictures, clips and sounds in context. This folder is the full option set behind every round, deliberately wide and not tuned to anyone's taste:
- **C** common: what most channels use. Safe, familiar.
- **R** rare: used by few channels. Distinctive.
- **F** funky: almost nobody uses it. Memorable, risky.

**Rules for using the catalog:**
- Every round shows a spread from all three tiers, even when the creator's personality points one way. Funky options often become moment looks or library items.
- Every option is shown, never described: a picture, a click-to-play clip, or a sound in sync with a picture. The name is in plain words, with one line of "what it is". No jargon on the page.
- Mark one option **Our pick for you**, with one line of why, based on the identity, the formats, the personality and the taste answers from Stage 4.
- Add new options freely when the creator's world suggests them (a texture, a set piece). Mark them as new, and still give them a universal name and use-when line.
- A round with too many options gets split (e.g. looks: natural and film first, then digital and funky).
- **Every option needs plain copy before it reaches a page:** a `line` (what it is, or "For: …" with a universal moment, like "For: a flashback"). Never the creator's niche: that stays in chat (`nicheWords` stops the build). The Look/description columns in these files are for Claude; never paste them onto a page.
- **The picture must show what the name says** (`voting-pages.md`, "Before publishing any page"). Where a row names its overlay or a purpose-made frame, build exactly that.
