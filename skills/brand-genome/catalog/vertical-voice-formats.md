# Catalog: vertical layouts, voice styles, formats

**Tier:** **C** common · **R** rare · **F** funky.

## Vertical layouts (Stage 8), shown in a phone frame with platform buttons drawn on

Built from the native vertical test photo (`10-car-vertical.jpg`, or the creator's own upright photo), drawn graphics and a plain gray silhouette for cut-outs; never another person's photo, never a 16:9 photo cropped to 9:16. Every mock has the safe box (x 65–930, y 250–1450) and the Instagram 3:4 grid crop (y 240–1680) drawn on.

**Framing families** (Stage 8 writes the framing spec per family):
- **Full face:** full-face, title-top, backdrop, listicle, zoom-frame, notes, comment-reply, title-behind, number-behind, green-room, drawn-world, floating-cards, crack, tilt, full-graphic (no face), story formats (no face).
- **Stacked** (16:9 band on top, face below): reaction, cutout-screen.
- **60/40 split** (content top 60%, face lower 40%): split, before-after, side-by-side.
- **Corner face** (face box lower left, content full frame): pip, floating-head, over-screenshot, pointing, stacked-reactions, notification, peek, shrunk.

Caption styles live in `graphics.md` only. On Shorts they follow the vertical spec in Stage 8.

## Short endings (Stage 8, step 6; chat, library)

| Slug | Name | What it is |
|---|---|---|
| loop-line | Loop line | The last line runs grammatically or visually into the first, so the replay is seamless |
| payoff-cut | Cut on the payoff | It ends the instant the point lands |
| deadpan-hold | Deadpan hold | A flat look to camera, 1 s or less, then cut |

### Short formats (vertical)

A Short format is its own show, never a cut-down of a long one. Each one names exactly one **Short shape** (the six below, same names in idea-genome and video-genome), has its own beats (hook → one point → payoff or loop), carries one message per Short (one sentence, ≤12 words) and ends on a Short ending, never an outro. **Source:** written and shot for vertical, the hook recorded fresh for vertical (the default). Mined from a long video only for a moment that passes the stranger test (a stranger who never saw the long video gets it and gets value), and still rebuilt tall with its own beats and a fresh hook. The long video's order never transfers.

The six Short shapes: **Payoff first → loop** (15–35 s) · **Myth-bust** (20–40 s) · **List of 3 or fewer** (25–45 s) · **Before / after** (15–40 s) · **Skit / POV** (15–45 s, ≤4 exchanges) · **Reaction / reply** (15–40 s; the reacted-to clip ≤ a third, the face in frame 1).

| Slug | Name | Tier | Shape | Beats | Length |
|---|---|---|---|---|---|
| short-tip | 30-Second Tip | C | Payoff first → loop | the result in 1–2 s → the one tip → proof that runs back into the hook | 15–35 s |
| short-story | Micro Story | C | Before / after | the end state in frame 1 → rewind → the turn → punchline | 15–40 s |
| short-myth | Myth Check | C | Myth-bust | the hyped claim → flat reaction → the one fact that kills it → button line | 20–40 s |
| short-list | Three Things | C | List of 3 or fewer | strongest item first (or a count that pulls) → two more → payoff | 25–45 s |
| short-skit | Both Sides | R | Skit / POV | the creator plays both sides, deadpan; each exchange escalates → payoff | 15–45 s |
| short-reply | Reply Short | C | Reaction / reply | face + hook in frame 1 → the clip or comment → their take → button line | 15–40 s |
| short-series | Numbered Short Series | R | any one of the six, named per series | "Part N" folded into the hook → one self-contained piece of a bigger build → payoff | 20–45 s |

Every part of a series passes the stranger test on its own; "Part N" never comes before the hook.
