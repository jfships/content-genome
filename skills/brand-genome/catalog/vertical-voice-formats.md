# Catalog: vertical layouts, voice styles, formats

**Tier:** **C** common · **R** rare · **F** funky.

## Vertical layouts (Stage 8), shown in a phone frame with platform buttons drawn on

Three sections on the page. Built from the face test photo (or the creator's own), drawn graphics and a plain gray silhouette for cut-outs; never another person's photo.

## Format recipes (Stage 3). Proposed from the identity and research; these are starting shapes

| Slug | Name | Tier | Structure | Length |
|---|---|---|---|---|
| how-to | How I Do X | C | hook result → steps → common mistake → final result | 6–12 min |
| build-along | Build / Make With Me | C | finished thing first → start → problems → solve → reveal | 8–20 min |
| myth-vs-fact | Myth vs. Fact | C | claim → why people believe it → test → verdict | 5–10 min |
| list-ranking | Ranked | C | criteria → bottom to top → surprise #1 | 8–15 min |
| day-in-life | Day in the Life | C | morning promise → the day in beats → evening payoff | 8–15 min |
| challenge | The Challenge | C | rules → attempt → twist → result | 6–15 min |
| reaction | Reacts To | C | clip → pause → their take → verdict | 6–12 min |
| before-after | Fix It | C | the mess → the plan → the fix → reveal | 6–12 min |
| deep-dive | Deep Dive | R | question → history → turns → answer | 12–25 min |
| versus | X vs. Y | R | contenders → rounds → winner | 8–15 min |
| experiment | I Tried X for N Days | R | rules → daily log → surprise → verdict | 8–15 min |
| teardown | Teardown | R | the thing → take it apart → what's inside → lesson | 8–15 min |
| letters | Answering Comments | R | comment → story or test → answer | 6–12 min |
| one-take | One Take | F | single unbroken shot doing the whole task | 3–10 min |
| silent | No Talking | F | no voice, only visuals, captions and sound | 2–8 min |
| mockumentary | Mockumentary | F | interviews and confessionals about an ordinary project | 6–12 min |
| rebuild-cheap | The Cheap Version | F | expensive thing → recreate it for less → compare | 8–15 min |
| short-tip | 30-Second Tip (vertical) | C | hook → one tip → proof | 15–45 s |
| short-story | Micro Story (vertical) | C | hook → turn → punchline | 20–45 s |
| short-series | Numbered Short Series (vertical) | R | "Part N" → one piece of a bigger build | 20–60 s |
