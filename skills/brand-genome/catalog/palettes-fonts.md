## Fonts (Stage 4.5)

**Every font here ships with the skill** (65 fonts in `page-template/fonts/`, offline, free licenses; `fonts.json` holds each one's job, tier and width `scale`). A page can use only these; a font not in `fonts.json` is skipped and said so in chat, never replaced by a system font. Each job's finalist page shows **20–30 tiles** (titles: all of them; text and notes: all of them, plus the two-job fonts), a C/R/F spread, sample words in the creator's colors, scaled by `scale` so wide fonts don't overflow.
