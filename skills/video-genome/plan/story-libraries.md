# Story libraries

The parts a video's content is assembled from. The brand dresses the result (look, motion, sound, voice); these libraries never decide those. Every library is open to every brand: the plan picks per video, filtered by the brand's personality, formats, truth rules and house rules.

## How to pick: the story stack

The plan names one **story stack** per video, by slug:

| Layer | Pick | From |
|---|---|---|
| Video type | 1 (a second only for a clear section change) | §1 |
| Script framework | 1 | §2 |
| Story arc | 1 | §3 |
| Hook | 3–6 options written, 1 kept in the edit | §4 |
| Proof | 1–3, the strongest first | §5 |
| Retention devices | 2–4 | §6 |
| Pacing pattern | 1 | §7 |
| Editing techniques | 3–6 allowed | §8 |
| Call to action | 1 main, at most 1 mid-video | §9 |
| Feeling target | 1 (from the Idea Record) | §10 |
| Platform mechanics | 0–2, vertical only | §11 |

The **angle** and **title formula** come from the Idea Record; don't re-pick them here (the plan only asks when the record has none).

**Compatibility check (gate 1).** Read the stack as one sentence: "A <type> that runs <framework> over a <arc> arc, opens on a <hook> hook, proves it with <proof>, holds with <retention>, cuts <pacing>, and ends with <CTA>, to make them feel <feeling>." If any part fights another, change one. Known clashes:
- Ticking clock + calm with bursts: the clock needs pressure; pick front-loaded or relentless.
- Mystery box + result-first hook: the result kills the mystery; pick curiosity gap or mid-action.
- Text-on-screen story + talking-head techniques (J/L cuts, punch-in): pick text-native moves.
- Relentless pacing + strategic silence more than once: one held pause, max.
- Faceless voiceover + real testimonial on camera: fine, but the testimonial is the only face; say so.
- Hard ask CTA + "entertaining" leading the personality: use soft or loop instead unless the brand says otherwise.
- Hook → Context → Payoff → Loop belongs to vertical; for long-form pick another framework. Shorts don't use the story stack: they pick one shape from `shorts/shapes.md`.

**Vary on purpose.** Read the last 3 episodes' stacks in `03 Videos/results-log.md`. Don't repeat the same arc and hook pair twice in a row unless the log shows it over-performing.

## 2. Script frameworks (order of information)

The format's beats (from the brand) are the episode's skeleton; the framework sets the order inside them.

| Slug | Framework | Order |
|---|---|---|
| hook-proof-process | Hook → Proof → Process → CTA | Show result, prove it's real, show how, ask |
| hook-problem-solution | Hook → Problem → Solution → CTA | Core short-form order |
| pas | Problem → Agitate → Solve | Name the pain, make it hurt, fix it |
| bab | Before → After → Bridge | Now, the dream, the way across |
| aida | AIDA | Attention, interest, desire, action (offers) |
| hook-context-payoff-loop | Hook → Context → Payoff → Loop | Minimal setup, payoff, end feeds the start (vertical) |
| ugc-ad | Hook → Context → Value → Proof → CTA | UGC ad order |
| claim-evidence | Claim → Evidence → So what | Opinions, myth tests |
| what-sowhat-nowwhat | What → So what → Now what | Fact, why it matters, what to do |
| question-answer-twist | Question → Answer → Twist | Obvious answer, then the surprise |
| objection-answer | Objection → Answer | Raise the viewer's doubt, settle it |
| mistakes-list | Mistakes list | N errors → why → the fix |

## 4. Hooks (first 3 seconds)

Rules from `run-sheet.md` still apply: prove the title within 10 s; never a greeting, backstory, agenda or logo. Every kept hook fires on three layers at once: the spoken line, the on-screen text, and the first image.

| Slug | Hook | Shape |
|---|---|---|
| result-first | Result first | Show the outcome, then how |
| proof-first | Proof first | Lead with the evidence |
| bold-claim | Bold claim | Strong, surprising statement |
| contrarian | Contrarian | Disagree with common advice |
| question | Question | One question they need answered |
| curiosity-gap | Curiosity gap | Name it, don't explain it yet |
| number | Number / stat | A specific, real figure |
| callout | Direct call-out | "If you run a restaurant…" |
| warning | Mistake / warning | "Stop doing this" |
| stakes | Stakes | What's at risk |
| mid-action | Mid-action | Drop in during the moment |
| secret | Nobody talks about | Hidden or insider information |
| pov-setup | POV setup | "POV: you just…" |
| visual-prop | Visual / prop | An object or image does the work |
| interrupt | Pattern interrupt | Something odd that breaks the scroll |

## 7. Pacing patterns (rhythm of cuts across the video)

The brand's motion table sets how things move; this sets how often cuts land.

| Slug | Pattern | Shape |
|---|---|---|
| front-loaded | Front-loaded | Fast early, eases off, late bursts |
| calm-bursts | Calm with bursts | Steady, quick-cut bursts every few minutes |
| return-hook | Return to the hook | Revisit the opening premise every few minutes |
| fast-talk-slow-show | Fast talk, slow show | Quick cuts while explaining, long holds on examples |
| cut-on-emotion | Cut on emotion | Cuts land on reveals, not a timer |
| cut-to-beat | Cut to the beat | Hard cuts on music hits (phrase length from the brand) |
| relentless | Relentless | Cut every 1–3 s, no air |
| one-take | One take | Unbroken; tension from the lack of cuts |

## 8. Editing techniques (cutting tools)

Transitions, camera moves and placements are in `craft/graphics-library.md` and the brand. These are cutting tools.

| Slug | Technique | Use |
|---|---|---|
| jump-cut | Jump cut | Remove pauses, same angle; vary shot size so it looks intended |
| jl-cut | J-cut / L-cut | Sound leads or trails the picture; smooth scene changes |
| smash-cut | Smash cut | Calm to loud with no warning; comedy, shock |
| match-cut | Match cut | Two shots lined up by shape or motion |
| punch-in | Punch-in zoom | Quick zoom on a key word |
| speed-ramp | Speed ramp | Slow for drama, snap back |
| cutaway | Cutaway | Brief shot of what's being said; hides a cut |
| pip | Picture-in-picture | Creator in a corner, other footage full |
| split | Split screen | Two things at once |
| letterbox | Letterbox moment | Bars animate in for a serious beat |
| freeze | Freeze frame | Stop on a face or moment, label it |
| rewind | Rewind / replay | Run it back to show it again |
| word-emphasis | Word emphasis | Key word circled or colored as spoken |

## 12. Named editing styles (reference only)

Shown to the creator as reference points when describing a feel ("faster, like X"). Never applied as a preset and never copied; the brand's look and motion always win. Hormozi (word-by-word captions, cuts every 1–3 s, punch-ins) · Ali Abdaal (clean, color pop on grey, handwritten captions) · MrBeast (huge stakes, constant re-hooks) · video essay / Johnny Harris (maps, archive, narration) · Casey Neistat vlog (handheld story, time-lapses) · Tom Noske Reels (cinematic B-roll intros, 3D-shadow captions).
