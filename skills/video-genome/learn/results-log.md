# Step 7: Results log

`03 Videos/results-log.md` is owned by **growth-genome**, its only writer (columns, rows, checkpoints and verdicts: growth-genome `templates/results-log.md`). video-genome never edits the file while growth-genome is installed. Its only job here:

- **When a post goes live, hand over the row:** post id, platform, surface, published date, the slot · lane · job from the Idea Record, and the Idea Record (link), one set per platform file. Run growth-genome with them ("log this post"), or, if this session can't, give the creator the fields in one block and tell them to run growth-genome's review.
- The script-level details (hook, shape/arc, beat start times, pace) live in the video's script card (script-genome); the row's Idea link reaches it, so a retention drop can be mapped to a line.

Without growth-genome installed (the only case where video-genome writes the file): add the same row yourself and, at 48 h and 28 d, ask the creator for numbers (one reminder each time they next open a session; never chase; never estimate a number). Judge against the creator's own median, not online benchmarks.

**Reading it** (before planning, and for idea-genome scoring): summarize in 3 lines which formats, angles, hooks and shapes beat the creator's median, and which fell below. With fewer than 5 posts, say the signal is weak and don't lean on it.
