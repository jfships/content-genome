# Step 6: Deliverables

## Long-form (YouTube)

- 16:9, at least 1080p; 4K when the source is 4K. No length limit; as long as the content earns.
- Chapters (timestamps from the plan's beats).
- Description from the brand's description template: hook line, what's inside, chapters, links, the call to action, any disclosure.
- 3 title candidates for A/B testing.
- 2–3 thumbnails (`craft/thumbnails.md`).
- The pinned comment from the brand's template.

## Vertical

- One file per moment, 1080×1920, with its caption text, cover frame and hashtags or keywords per platform.

## Files and naming

- Name finished files after the creator, the episode and the purpose, e.g. `<handle>-ep03-final.mp4`, `<handle>-ep03-short1.mp4`. Say plainly which file is the finished video; clips and previews are only for re-editing.
- Keep old renders; version new ones (`-v1`, `-v2`).
- If a transfer to the creator's computer has a size cap, re-encode a review copy to fit (e.g. H.264 at 720 kbps, AAC 128k) and keep the full-quality master where it was rendered until the episode ships.
- Transparent overlay clips: also export a `.webm` with alpha for other editors if the creator wants to re-edit.

## Final checklist (part of gate 3)

- Duration, resolution, frame rate and file size match each platform's current spec.
- Audio at target loudness.
- Captions match the cut transcript (only intentional filler removals differ).
- Disclosure labels noted where needed.
- Every file opens and plays from the start.


After delivery, run the brand review (`review/session-close.md`).
