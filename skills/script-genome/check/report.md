# Check report format (job B)

Plain words. No score, no ranking, no "wrong shape". Quote lines. Keep it to one screen when possible.

```
SCRIPT CHECK · <title or file> · <date>
Target <s> s · spoken words <n> (main hook/ending; alternatives one line each) · est. <s> s at <pace> w/s · stage: <from strategy block or "no audience yet">

VERDICT: FIX FIRST | NEEDS YOU | CLEAR TO RECORD
  FIX FIRST  = any hard gate FAIL
  NEEDS YOU  = a hard gate NEEDS-INFO or a judgment call only the creator can make
  CLEAR TO RECORD = all hard gates PASS or N/A (notes are advice)

A. HARD GATES (only non-PASS rows shown; then "all other gates: PASS / N/A")
   ID | status | "quoted line" | why, one sentence | smallest fix | confidence | who decides

B. WHAT IT DOES (no labels)
   Opening: who it's for + what they get, by ~3 s? yes/no · "line"
   Middle: what proof is shown?
   Payoff: what lands; does it match the promise?
   Ending: the one ask, or none; allowed at this stage?

C. CRAFT NOTES (S1–S13 that are absent or unusual; quote + "ignore if …"; news topics always get S13 freshness: when did this break, is it still new?)

D. HOUSE FLAGS (brand house rules; advisory)

E. CAN'T CHECK FROM THE SCRIPT (who confirms)
   disclosure placement · partnership label · music rights · facts re-verified on <date> · AI label

F. FIXES (≤5, gates first, smallest first)
   1. "<old line>" → "<new line>"  (why)
```
Rules: re-check only changed lines after a fix round. Several hooks or endings given: count the first-listed one, report the others one line each. Elided text ("…") → C3 NEEDS-INFO. An ask outside the stage policy → a craft note + a house flag, not a gate (unless L9 bait). If the script was written by this skill, also attach the lint result (`card/lint.md`). Weak-evidence notes say so in plain words ("one creator's habit, untested").

## False positives

Things that look like a problem and usually aren't. Note them, don't fail them; a human decides.

From the gates ("Ignore if"):
- L1 disclosure when there is no connection (nothing needed; no "not sponsored" line).
- L2 / L5 / L10 when there is no brand deal, no result number, no income claim.
- L3 / L4 for opinion clearly marked as opinion or hearsay ("I like it").
- L6 for a clearly labeled skit or example.
- L7 for AI used only for scripting, captions, color, spelling, or obviously fantastical art.
- L8 for a remix or reaction with real added commentary.
- L9 for a situational "send this to the friend who…" line (flag only if generic or a quota); keyword-for-resource asks are UNCERTAIN, the creator decides with the stage.
- A3 for lines marked `new` that are wording only, no new fact.
- C1 for a two-part script where part two is the payoff · C3 for silent demo beats · C4 for a deliberate long build-up · C5 when the audience is expert.

Rules that reject good scripts (do not apply them as rules):
1. "No rhetorical questions" vs question hooks.
2. "Cut weak hedges" vs honest uncertainty: keep one calibrated qualifier.
3. Contraction counts vs deliberate emphasis or a formal personal brand.
4. Sentence-length variance vs a deliberately staccato style.
5. Word-count caps vs silent visual beats and demos (the budget is for spoken words).
6. AI-word flags vs people who really say "crucial", and vs non-native phrasing.
7. Readability scores (Flesch etc.): invalid for speech; don't run them.
8. Disclosure checks when there is no connection.
9. The engagement-bait scan flagging a relevant situational send line.
10. "Must have a CTA" or "must have a question hook": never shape rules; test the function only.
11. "Don't read statistics" vs a teaching niche that needs a number: put it on screen and say it simply.
12. "Cut by a fifth" on an already-tight script or one whose proof beat would die.
13. Emotion/arousal checks that push toward outrage (bait risk; plain often scores better than hype).
14. Positive-word or word-category counts as a quality metric (crude, correlational).
