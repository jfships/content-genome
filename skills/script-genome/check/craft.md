# Craft notes (reported, never failed)

Report each as present / absent / n.a., with the quoted line. A note that breaks a craft norm while the function works = "present but unconventional, no action".

| ID | Observation | Basis (grade) | False-positive note |
|---|---|---|---|
| S1 | Specifics: each beat has a number, name, screen action, time or before/after. | Concreteness research (RESEARCH, other media); practitioner consensus | An abstract framing beat may be on purpose. |
| S2 | At least one feeling beat: surprise, awe, "you've been there", amusement, relief/usefulness. Not forced hype. | Berger & Milkman 2012 (high-arousal and practical content shared more, sadness less; text, not video); System1 ad data (vendor) | Don't push toward outrage; hype scores worse than plain. |
| S3 | Spoken voice: contractions, mixed sentence lengths, fragments allowed. | Speech vs writing linguistics; detector-vendor tells (weak) | A deliberate staccato or formal personal style. |
| S4 | AI/script tells: flag only clusters (3+ groups in `voice/tells.md`). | Word-frequency studies (written); speech adoption study | People now say these words; non-native speakers get false flags. |
| S5 | Humor (optional) where attention would sag or as the button; never on the claim. | Ace Metrix TV ads (vendor, correlational) | Humor never replaces the payoff. |
| S6 | ABCD lens: Attention early (face/voice/claim), Brand (who is speaking and why follow), Connection (one focus, a human feeling), Direction (clear next step or none). | Google/Ipsos/Kantar (YouTube ads; vendor-run) | Never pass/fail; a lens only. |
| S7 | Generic test: could any other creator read this about any other product? | Human AI-text detection research; vendor | Beginner topics are generic by nature: add the creator's proof. |
| S8 | One natural take: the creator can say it without stumbling. | Practitioner | Needs the creator. |
| S9 | Re-hook between ~40–70% for videos ≥30 s; a new reason to keep watching roughly every 8–12 s. | Long-form practitioners, scaled (INFERENCE) | Very short videos may need none. |
| S10 | Peak in the last third; last beat not sad or flat. | Peak-end (lab), Berger & Milkman (text), Ely et al. (theory) | A deadpan button is low-energy on purpose. |
| S11 | Order checks: competence shown before any failure beat; fact before myth (one myth, ≤3 counter-points); reveal last, twists bigger and rarer; re-anchor after a twist. | Pratfall research; Debunking Handbook; suspense theory; ad eye-tracking | Only when that beat type exists. |
| S12 | Variety: not the same shape/arc + hook pair as the last 3 videos (results log). | House variety rule | Unless the log shows it over-performing. |
| S13 | Freshness (news topics): when did this break; is it still new on the day it posts? Undated "just happened" lines get a date or "as of <month>". | INFERENCE (craft). Flag: weak | Evergreen topics; a news item used only as an example. |

House rules (from the brand's `house-rules.md`) are listed separately as HOUSE FLAGS and never fail a script.
