# Sounds-like-AI / sounds-like-a-script flags

Review flags, never auto-fails. Flag a script only when **3 or more groups** show up. The fix is never synonyms: add the creator's own specifics (a name, a number, what happened, a screen).

Evidence: word-frequency studies of academic writing after 2022 (written text); a study showing these words spread into unscripted podcast speech and that people adopt a chatbot's words after brief use (so single words prove nothing); detector studies that wrongly flag non-native writers; a detector vendor's published list of structural tells (weak).

| Group | Flags |
|---|---|
| 1. Vocabulary | delve, tapestry, pivotal, underscore, showcase, intricate, landscape, realm, testament, robust, seamless, elevate, embrace, navigate (as metaphor), foster, crucial, vibrant, meticulous; marketing set: unlock, game-changer, supercharge, dive into, level up |
| 2. Stock phrases | "it's important to note", "in conclusion / overall", "plays a crucial role", "serves as", "shed light on", "paving the way", "when it comes to", "here are some" |
| 3. Frames | "not only X but also Y"; "it's not about X, it's about Y" (very common in machine-written hooks) |
| 4. Rhythm | every sentence the same length; every sentence complete and grammatical; no fragments; few contractions |
| 5. Structure | tidy triplets everywhere; symmetric lists; a closing line that restates the premise |
| 6. Tone | relentlessly upbeat, formal, never critical |
| 7. Content | generic: no proper nouns, no personal experience, no number, no screen detail; default names (Sarah, Emily) |
| 8. Punctuation (captions) | em dashes everywhere |
| 9. Script tells (not AI-specific) | written syntax (noun-stacks, subordinate clauses); reads statistics aloud with no screen support; opens by announcing itself ("in this video I'll show you"); slogans nobody says out loud; no contractions |

**Best single test:** could this exact script be read by any other creator about any other product? If yes, it's generic: add proof.

False positives: a creator who naturally says "crucial" or "delve"; careful or non-native speakers; deliberate formal brands; one word on its own.
