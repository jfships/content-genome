# Learn from the creator's own numbers

No hook, shape, arc or ending has been tested on 20–60 s Reels by anyone who published a method. The creator's Insights are the only real test. `03 Videos/results-log.md` is owned by growth-genome (its columns, checkpoints and verdicts); growth-genome writes the row when a post goes live (video-genome hands it the fields). script-genome adds nothing to the log: the script fields below live in the saved script card, which the row reaches through its Idea Record link. Without growth-genome, keep a simple `results-log.md` next to the saved scripts with the fields below.

## What Instagram actually reports (official)
Skip rate (share of views that left within 3 s; no official benchmark) · retention chart (always slopes down; flatter is better; a bump = replays) · average watch time · views (replays count) · likes, sends/shares, saves, comments, follows per reach. Mosseri (Jan 2025, reported): watch time, likes per reach and sends per reach matter most; sends weigh more with non-followers. Judge by rates, not counts.

## Script fields (in the script card header; the log links to it)
Before posting: script file · date · core claim · runtime target · spoken words · pace · hook (three layers, verbatim) + hook slug · shape/arc/operator slugs · beat start times · ending slug + ask · stage · trial or regular · posting time · followers at post · check verdict · the creator's guess written before posting ("skip rate below my median").
At 24 h / 72 h / 7 d: views · non-follower share · skip rate · average watch time · retention at ~3 s, middle, end · **drop timestamps mapped to the beat and line** · likes/reach · sends/reach · saves · follows.
Review: the line at the biggest drop · one change for next time · was it the script, the topic or the visual?

## Reading the retention chart (practitioner readings, directional)
Sharp drop in 0–3 s → opening. Good start then a cliff → the body doesn't match the hook (check the line at that time). Gradual slide → pacing, low information. Drop right after a payoff → the next question wasn't opened. Late drop → ending runs long. Bump → people replayed a moment: reuse that beat.

## Fair comparisons at small numbers
- Pick the metric before posting: hook test → skip rate and early retention; body test → mid retention; message test → sends and saves per reach. Don't hunt the dashboard for a winner afterwards.
- Change one thing. For a hook test, change only the first 1–3 s; same body, caption and cover.
- Trial vs trial, never trial vs a normal post. Trial Reels eligibility varies (sources say 200–1,000 followers; check whether the toggle appears). No toggle → post normally and compare against the creator's own median of the last ~10 videos.
- Read at the same time (72 h). No peeking and stopping early.
- Noise: at ~300 views each, gaps under ~8 percentage points are noise. Same-direction results across pairs: 1–2 pairs = nothing, 3–4 = a lean, 6+ = decent evidence.
- Pool by beat function across videos ("the reveal", "the bottom of the dip"), not by arc name: small accounts never get enough posts per arc.
- Fix order: hard-gate fails → the biggest retention cliff line → then test hooks. Don't A/B a script that has an unexplained cliff.

## Cadence
Weekly: read the log. Monthly: recompute the creator's medians; check Account Status for recommendation eligibility. Quarterly: re-verify the ⟳ items in `check/gates.md`. Change a skill default only after repeated, logged results; write the reason in the brand's decisions.
